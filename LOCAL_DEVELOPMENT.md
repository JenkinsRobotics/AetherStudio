# Alpha 0.1 development

See [ALPHA_0_1.md](ALPHA_0_1.md) for package retrieval and current limits.
The release source is isolated from ongoing local development. Internal live
claims, mailboxes and machine-specific deployment history are not release inputs.
Use a new branch for changes; preserve the product and shared-library boundaries
in AGENTS.md. Run the owning package tests and build before proposing a change.
