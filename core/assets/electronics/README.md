# Electrical artwork

Original code-native path artwork for the Aether IO UI draft. These resistor,
capacitor, LED, switch, connector and microcontroller symbols are rendered by
`@aether/ui`'s `CircuitSymbol` and demonstrated in the central showcase.

This directory contains presentation geometry only. Pin identity, electrical
values, connection graphs and simulation behavior belong to the product.
These drawings do not claim compliance with an electrical drafting standard.
