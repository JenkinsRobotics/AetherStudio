# Avatar studio artwork

Original demo artwork generated with the built-in imagegen tool on 2026-10-15.
`presenter.png` preserves the generated alpha channel. `woodland.png` is a separate
environment. The user's screenshot guided the app composition, not character identity.
Original outputs remain under the Codex generated_images directory.

Prompts are recorded in `prompts.json`. These are illustration assets for the UI
demo, not a rigged avatar, tracking model or live camera source.
