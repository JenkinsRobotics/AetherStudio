# Aether startup backgrounds

Three original raster backgrounds generated with the built-in image_gen tool on
2026-10-11: precision.png (machined forms), flow.png (glass ribbons), spatial.png
(layered terrain). Full prompts are in prompts.json. Each is 1672 × 941 pixels.

Artwork contains no app title, logo or progress UI. The lower third is quiet so
ApplicationSplash can render accessible, live startup content above it. These
backgrounds can be reused across apps; select once at startup rather than cycling
behind loading text. Keep originals intact when adding variants.

The gallery preview at ?demo=application-splash combines the artwork with the
complete splash and has background/state controls. Runtime adoption is future work.
