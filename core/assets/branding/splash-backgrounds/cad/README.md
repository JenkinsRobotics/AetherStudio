# CAD splash collection

Subject-led CAD artwork: robotic gripper, wheel/hub assembly and electronics
enclosure. These generated concept renders illustrate the kinds of objects a
CAD tool is for; they are not exported Aether CAD documents or manufacturing
validation. Generated with built-in image_gen; exact prompts in prompts.json.

Keep titles, progress and startup stages as live ApplicationSplash controls.
The previous abstract collection is preserved as exploration, not the CAD default.
Future app collections should depict each app's authored output, not generic art.
