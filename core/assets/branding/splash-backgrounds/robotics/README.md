# Robotics splash concepts

Four original generated backgrounds: humanoid.png, rover.png, vtol.png and
underwater-rov.png. Built-in image_gen; full generation prompts in prompts.json.
These are concept artwork, not validated mechanical models or CAD exports.
App name, progress and stage labels remain separate live UI. Original images
are preserved. Not yet packed or adopted by startup/gallery; existing immutable
archives and consumers are unchanged. Check each crop against the overlay before
adoption, particularly the full-height humanoid.
