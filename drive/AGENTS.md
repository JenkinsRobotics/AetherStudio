# Aether Studio Drive module

This is the active Drive frontend, bundled with the Aether Studio server in
`AetherStudio`. Follow the parent AGENTS.md and LOCAL_DEVELOPMENT.md.
Drive is a server-backed workspace, not an independently released offline app.
Its backend storage, permissions, sharing and history remain in the platform.

Preserve the versioned UI/session/artwork dependencies and existing Drive routes.
Do not change the preserved original installation. The former sibling
`aether-drive` repository is an inactive history backup; do not develop there.
