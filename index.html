// what it is

Your team's server: accounts, shared files, versions and live collaboration.

Aether Studio is the server behind the Aether apps. It hosts the apps, stores every document with full version history, manages accounts and permissions, and connects your AI providers once for every app.

It is built for performance first: a native server designed for hundreds of simultaneous live connections on modest hardware, with Raspberry Pi players and any browser as clients.

Aether Drive, accounts and PDM — on your own hardware. Part of the Aether apps: open-source tools for designing, animating and running real-world shows and machines.

// built-in ai

Your AI, using the server’s own tools.

Connect ChatGPT, Claude or Gemini once in Aether Studio. Agents work through the same commands you use — validated, undoable and recorded — never through screen-scraping. AI is optional: nothing you save ever needs it. works today

  • Studio owns the connection to your AI provider and grants each app's agent only the tools that app exposes.
  • Every agent operation is scoped, revision-checked and recorded with a receipt, and the same tools are available from the command line and MCP.
  • The same tools are available from the command line and as MCP tools, with scoped permissions and safe retries.
agent — bash
$ aether-agent run map.scene.create --operation-id create-side-scene < scene.json

Can I use it for real work yet?

Try it, test it and tell us what breaks — but keep copies of anything important. Alpha file formats can change, and features marked in progress or planned are not finished.

Do I need a server?

No. Each app keeps its core features on one machine. Aether Studio adds sharing, versions, multi-user work, AI connections and access from any device.

Do I need AI?

No. AI is an optional helper that uses the app’s own tools. Everything you make opens, edits and plays without it.

Who owns my files?

You do. Apache-2.0 software, open formats, and storage on hardware you choose.
