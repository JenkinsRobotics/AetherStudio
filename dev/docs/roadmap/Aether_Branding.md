## Names and application scope

Use **Aether** in prose and **AETHER** in display wordmarks. The supplied sheet
labels the animation artwork **Aether Animate**; the implemented application
is currently named **Aether Animation** in this repository. This guide records
that artwork label without changing package identifiers or product routes.
Sketch and Vector now have launchable product packages with shared UI
**Coming soon** homepages. Their drawing and vector creation tools remain planned.

Map's separate supplied reference now has a [square icon](../../../core/assets/branding/new-aether-2026-09/aether-map.png)
and [wide projection hero](../../../core/assets/branding/new-aether-2026-09/aether-map-hero-v2.png).
The built-in image tool derived both from that reference; [initial prompts](../../../core/assets/branding/new-aether-2026-09/MAP-PROMPTS.md)
and [final hero prompts](../../../core/assets/branding/new-aether-2026-09/HOME-ART-PROMPTS.md)
are preserved. The shared Map icon, library home, launcher card and browser shortcut
use this identity. All seven applications use rounded PNG derivatives from the
new family for compact app chrome, browser icons and desktop shortcuts.

## Using the assets

- Use the shared [PNG masters](../../../core/assets/branding/new-aether-2026-09/)
  as the source for documentation and future application exports. Clean and
  named icons are 1254 × 1254 pixels, RGB, with an opaque background.
- Keep square proportions and the full canvas. Preserve the A's negative
  spaces, facet structure, product treatment and surrounding breathing room.
- Use the navy backgrounds for Studio, CAD, Vector and Animate, and the pale
  paper treatment for Sketch. These files are not transparent cutouts.
- Put readable product names beside or below an icon using live text. Supply
  meaningful alt text. Tiny toolbar controls continue to use the shared
  interface icon vocabulary.
- Keep generated derivatives in this versioned directory. Preserve the
  [original artwork archive](../../../core/assets/branding/originals/README.md)
  and earlier logo variants.

## Provenance and integration state

Generated using the built-in image-generation tool, one call per application,
with Jonathan's attached five-tile sheet as the identity reference. These are
new raster derivatives, not the original supplied image or editable SVG masters.
The exact [prompt set](../../../core/assets/branding/new-aether-2026-09/PROMPTS.md)
and [asset manifest](../../../core/assets/branding/new-aether-2026-09/manifest.json)
accompany the artwork.

The new family now supplies every application's small chrome icon, Safari
favicon, web manifest icon and macOS browser shortcut through the active
`core/assets/branding/apps/` PNGs. They use a common rounded silhouette and
transparent corners. Full-size marks supply the shared large welcome panels.
Sketch and Vector have wide 16:9 hero companions, and Map's active wide image
is `aether-map-hero-v2.png`. [Final prompts](../../../core/assets/branding/new-aether-2026-09/HOME-ART-PROMPTS.md)
record these image-tool derivatives; `build-web-icons.py` records the
deterministic small-icon render and versioned URL pipeline.
